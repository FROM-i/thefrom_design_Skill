## 1. 이름

**THE FROM (더프롬)** — 모든 Creative는 결국 **나로부터** 시작되어 발현된다.

이것은 사명이 아니라 작업 방식의 선언이다. 레퍼런스에서 시작하지 않고, 트렌드에서 시작하지 않고, 판단하는 사람에게서 시작한다는 뜻이다. 그래서 이 방법론의 모든 단계에는 "누가, 무엇을 근거로 그렇게 판단했는가"가 기록되어야 한다.

### 1.1 철학은 판단의 방법이지, 결과물의 소재가 아니다 `[제안]`

이 문서에 적힌 더프롬의 것들 — 이름의 서사("나로부터"), 1U와 로고 형상, 브랜드 컬러, airplane·tunnel — 은 **우리가 어떻게 판단하는가**를 정한다. **클라이언트 결과물에 무엇을 그리는가**를 정하지 않는다.

| 층위 | 쓰는 곳 | 쓰지 않는 곳 |
|---|---|---|
| 판단의 방법 | 모든 프로젝트의 과정 — 무엇을 가져오고, 무엇에 반대하고, 언제 출구로 나가는가 | — |
| 더프롬의 얼굴 (로고 형상·브랜드 컬러·서사) | 더프롬 자사 산출물 | **클라이언트 결과물의 모티프·메타포·팔레트** |

결과물에서 더프롬이 보인다면 그것은 방법이 잘 작동한 흔적이 아니라, 방법이 결과물에 새어 나간 것이다. 좋은 결과물에서 더프롬은 **판단의 질**로만 드러난다(→ N7).

> **우선순위** — 판단이 부딪히면 **사용자 경험과 조형 완성도가 방법론의 형식보다 앞선다.** 방법론은 좋은 디자인에 도달하기 위한 장치이고, 형식을 지키느라 결과가 나빠지면 형식이 틀린 것이다(→ §6.7).

## 2. 1U — 단위 체계

### 2.1 로고에서의 1U (확정)

| 항목 | 규격 |
|---|---|
| TOP | 3U |
| MID | 2U |
| BTM | 1U (정사각형) |
| Gap | 0.1U |
| 정렬 | 좌측 정렬 |
| 각 | 모든 각 직각 |
| 안전 여백 | 1U 이상 |

**1U의 정의**: BTM의 정사각형 한 변. 이 하나의 정사각형에서 로고의 모든 치수가 파생된다.

**의미**: 1 Unit에서 모든 것이 시작된다. 로고가 그 명제의 증명이다.

### 2.2 설계 단위로서의 1U (확정)

로고에만 적용되던 규격을 **모든 산출물의 설계 단위로 확장한다.** 근거는 1U 자체의 의미다 — "1 Unit에서 모든 것이 시작된다"가 로고에만 해당한다면 그것은 로고 규격서이고, 방법론이 아니다.

**단, 이것은 모든 설계에 무조건 도입하는 불변의 원칙이 아니다.** 두 문장이 모순되지 않는 이유는 다음 구분에 있다.

> ### 1U는 값이 아니라 방법이다.

| | 고정되는 것 | 프로젝트가 정하는 것 |
|---|---|---|
| **방법** | 하나의 단위를 정하고 **모든 치수를 거기서 파생시킨다** | — |
| **값** | — | 1U가 8px인지 4px인지 12px인지 |

"1 Unit에서 모든 것이 시작된다"는 특정 숫자에 대한 선언이 아니라 **파생 구조에 대한 선언**이다. 그래서 값이 프로젝트마다 달라도 원칙은 유지되고, 값을 브랜드 상수로 못 박지 않아도 1U는 작동한다.

**따라서 1U 위반은 "8px을 안 썼다"가 아니라 "파생 근거가 없다"다.**

### 2.2.1 기본값 — 웹·앱 (프로젝트가 교체 가능)

| 층 | 1U의 값 | 파생 |
|---|---|---|
| 로고 | BTM 한 변 | TOP 3U / MID 2U / Gap 0.1U |
| 간격 | 8px | 0.5U(4) / 1U(8) / 2U(16) / 3U(24) / 5U(40) / 8U(64) |
| 타입 스케일 | 본문 = 2U (16px) | 본문 2U / 소제목 3U / 제목 5U / 대제목 8U · `[제안]` 스케일 종류별로 0.25U·0.5U 조건부 허용 → §2.2.5 |
| 그리드 | 거터 = 2U | 마진 = 4U 이상 (안전 여백 1U 이상 규칙의 확장) · `[제안]` 모바일(폭 360~430px)은 **3U** — 4U는 본문 폭을 과하게 줄인다 |
| 코너 반경 | 0.5U / 1U / 2U 3단계 | 그 외는 근거를 요구 |

> 이 표는 **출발점**이다. 프로젝트가 다른 값을 쓰기로 하면 그 값으로 표를 다시 쓰고, 파생 구조는 그대로 유지한다.

### 2.2.2 세 가지 제약 — 기본값이며 근거로 이탈 가능

로고 규격에서 가져온다. 셋 다 **기본값**이고, 이탈에는 근거 기재가 필요하다(→ L1 S3 게이트 U2).

1. **좌측 정렬이 기본이다.** 중앙 정렬은 근거를 요구한다.
2. **모든 각은 직각이다.** 사선과 곡선은 근거를 요구한다. (→ `CON-DIR`, `COMP-DIA`는 근거가 있을 때만)
3. **안전 여백 1U 이상.** 어떤 **독립 요소**도 1U보다 가까이 붙지 않는다.
   `[제안]` **0.5U는 컴포넌트 내부 간격에만 쓴다** — 아이콘-라벨, 배지-텍스트, 입력창 안의 아이콘-값처럼 하나의 컴포넌트를 이루는 요소 사이. 독립 요소(카드와 카드, 버튼과 버튼, 제목 블록과 본문 블록) 사이는 1U 이상이다. §2.2.1 간격 표의 0.5U(4)는 이 범위에서만 유효한 값이다.

### 2.2.3 1U를 적용하지 않는 경우

아래는 **예외가 허용되는 상황 목록**이다. 이 목록에 없는 이탈은 예외가 아니라 누락이다.

| 상황 | 이유 | 그래도 지키는 것 |
|---|---|---|
| 클라이언트 디자인 시스템이 이미 있는 경우 (삼성·한화 등) | 클라이언트 시스템이 상위다 | 클라이언트 단위 안에서 파생 구조를 유지한다 |
| 외부 플랫폼 규격이 강제되는 경우 (미니앱·키오스크·스토어) | 플랫폼 제약이 상위다 | **플랫폼 단위를 1U로 삼는다** |
| 인쇄·환경 그래픽 | 물리 단위(mm) 체계가 다르다 | mm 기준 1U를 새로 정한다 |
| 기존 자산 확장 | 기존 값과의 불일치가 더 나쁘다 | **기존 값을 1U로 역산한다** |
| 단발 키비주얼·실험 작업 | 시스템이 필요하지 않다 | 비율(`RATIO-*`)만 특정한다 |

**모든 예외에서 버리지 않는 단 하나**: "이 치수는 어떤 단위에서 파생되었는가"에 답할 수 있어야 한다. 답이 "없음"이면 그것은 예외가 아니라 N2(근거를 설명할 수 없는 조형) 위반이다.

### 2.2.4 1U는 보이지 않는 뼈대다 `[제안]`

> **사용자가 1U를 알아볼 수 있다면 실패다.**

1U는 치수가 어디서 왔는지를 설명하는 **내부 구조**다. 스위스 그리드가 "보이지 않는 뼈대"였던 것처럼(→ `GRID-*` 원문 `보이지 않는 뼈대 역할을 함`), 1U는 결과물의 질서감으로만 느껴져야 하고 형상으로 드러나서는 안 된다.

| 1U를 쓰는 방식 | 판정 |
|---|---|
| 간격·타입·반경·그리드가 한 단위에서 파생되어 화면이 정돈되어 보인다 | 정상 — 뼈대 |
| 정사각형 단위·막대 쌓기·3U/2U/1U 비례가 화면의 **모티프**가 된다 | **실패** — 1U의 상징화 (N7) |
| 1U 규칙을 지키느라 가독성·위계·미감이 나빠진다 | **실패** — 1U 값을 바꾼다. 미감을 1U에 맞추지 않는다 (§6.7) |

### 2.2.5 타입 스케일의 단위 — 0.25U는 조건부로 `[제안]`

정수 U만으로는 한글 모바일 UI의 타입 위계가 나오지 않는다. 8px 기준으로 16·24·40·64px 사이에는 본문 보조(14px), 목록 제목(17~18px), 소제목(20~22px)이 들어갈 자리가 없다. 그래서 **타입에 한해 더 작은 단위를 허용하되, 스케일의 종류에 따라 조건을 둔다.** 간격·반경·그리드는 이 절의 대상이 아니다(최소 0.5U, 0.5U는 컴포넌트 내부만 — §2.2.2).

| 스케일 종류 | 쓰는 곳 | 최소 단위 | 허용 조건 |
|---|---|---|---|
| **UI 스케일** | 본문·라벨·캡션·버튼·목록·입력 | **0.25U** | ① 1.5U~3U 구간(8px 기준 12~24px)에서만 ② 한글 가독성·플랫폼 최소 크기·줄 길이 중 하나를 근거로 적는다 ③ **스케일 표에 등록한 단계만** 쓴다 — 최대 5단계 ④ 인접 단계의 비율이 1.125 이상 (구분되지 않는 단계는 만들지 않는다) |
| **디스플레이 스케일** | 표제·히어로·강조 숫자 | **0.5U** | 정수 U가 기본. 0.5U는 줄바꿈 위치·화면 폭 근거가 있을 때만. 최대 3단계 |
| **행간** | 모든 텍스트 | **0.25U** | 줄 높이는 0.25U의 배수로 쓴다 — 서로 다른 크기의 글이 같은 리듬 위에 놓이게 한다 |
| **인쇄·환경** | 지면·사이니지 | mm 1U | §2.2.3 예외를 따른다 |

**0.25U는 파생이다.** 스케일 표에 등록한 0.25U 단계는 U1(파생 근거)을 통과한다 — 1U를 4로 나눈 것이기 때문이다. 표에 없는 값(예: 15px을 한 곳에만)은 등록되지 않은 값이므로 U1 실패다.

```
UI 스케일 예 (1U = 8px)
캡션 1.5U(12) · 보조 1.75U(14) · 본문 2U(16) · 목록 제목 2.25U(18) · 소제목 2.75U(22)
디스플레이   표제 4U(32) · 대표제 5.5U(44) · 히어로 8U(64)
행간         본문 3U(24) · 보조 2.5U(20) · 표제 5U(40)
```

### 2.3 1U가 하는 일

1U는 **의사결정 비용을 줄이는 장치**다. 간격을 매번 협상하지 않기 위해 존재한다. 그래서 1U의 성공 기준은 "아름다운가"가 아니라 **"이 값을 왜 썼는지 설명할 필요가 없어졌는가"**다.

스위스 스타일이 그리드로 한 일이 정확히 이것이다(→ `ISM-SWISS`). 차이는 스위스가 **그리드를 짜는 방법**을 남겼다면, 우리는 **파생의 출발점이 하나여야 한다는 규칙**을 남긴다는 점이다. 값을 고정하는 것이 아니라 구조를 고정한다.

### 적용 범위 `[제안]`

**이 팔레트는 더프롬 자사 산출물(브랜드·사내 서비스·제안서 등)의 컬러다.** 클라이언트 작업의 컬러는 **클라이언트(서비스)의 브랜드**에서 가져온다(→ L1 S2 컬러 역할 배분). 클라이언트 브랜드가 정의되어 있지 않으면 묻고(→ `Q-S0-06`), 답이 없으면 서비스의 약속과 타겟에서 새로 정한다. 더프롬 팔레트로 공백을 채우지 않는다(→ §1.1, N7).

### 노랑의 의미

아이부터 노년까지 **전 세대**. 노년이 되면 다시 아이가 된다는 인문적 의미를 담는다. 즉 노랑은 "밝고 활기찬 색"이 아니라 **전 연령이 즐길 수 있는 디자인**이라는 태도의 표기다.

**중요 — 오해 금지**: 코어 컬러라는 것이 "항상 쓴다"는 뜻은 아니다. UI/UX에서 노랑을 항상 쓰지 않는다. 노랑은 **브랜드의 태도를 지시하는 색**이고, 화면에 반드시 등장해야 하는 색이 아니다.

> 이 구분이 무너지면 모든 산출물이 노란색이 되고, 노랑이 의미하던 "전 세대"는 사라진다. 색은 팔레트가 아니라 코드다 — 한국 전통 미학의 오방색이 정확히 같은 구조다(→ `ISM-KR`).

## 4. Airplane Effect — 여행

### 4.1 정의

다양한 디자인 철학과 ism을 **경계 없이 여행하고 믹스**해, **근본 있는 하이브리드**를 만든다.

### 4.2 "근본 있는"이 제약이다

여행은 자유롭지만 결과물은 근본이 있어야 한다. 이 두 조건을 동시에 만족시키는 것이 airplane effect의 어려운 지점이고, 다음 세 가지 규칙이 그 조건을 구체화한다.

**규칙 1 — 사조는 원리 층위에서 가져온다. 시각 층위에서 가져오면 코스튬이 된다.**

| 가져오는 것 | 가져오지 않는 것 |
|---|---|
| 바우하우스의 "장식은 금지 대상이 아니라 입증 대상" | 원·삼각형·사각형 + 3원색 |
| 데 스틸의 "불균등 면적 비율에서 성립하는 긴장" | 적·황·청 + 굵은 검정 격자 |
| 브루탈리즘의 "무엇을 숨기지 않는가" | 굵은 검정 테두리 + 형광 노랑 + 하드 섀도 |
| 일본 미학의 "완결을 유보해 수신자의 참여를 요구" | 크라프트지 텍스처 + 미색 배경 |

시각 층위에서 가져온 것은 즉시 인식되는 인용이 되고, 브랜드의 고유성 대신 미술사 레퍼런스만 전달한다. 이건 여행이 아니라 면세점 쇼핑이다.

**규칙 2 — 무엇을 가져오는지와 함께, 무엇을 두고 오는지를 기록한다.**

사조마다 계승 불가능한 부분이 있다. 절대주의는 명시적으로 비기능적이므로 affordance를 삭제하면 사용성 결함이 된다. 미래주의는 파시즘과 실제로 결합했으므로 브랜드 서사로 쓸 수 없다. 이것들은 "주의사항"이 아니라 **판단의 절반**이다.

L2 카탈로그의 모든 `ISM-*` 항목은 `가져올 것` / `두고 올 것` 두 칸을 반드시 채운다.

**규칙 3 — 반대 대상이 없는 파괴는 파괴가 아니다.**

멤피스도, 카슨도, 펑크도, 다다도 지배적 규범을 정확히 겨눈 반작용이었다. 표적 없이 형식만 빌리면 남는 것은 주장 없는 소음이다. 실험적 조형을 쓸 때는 **무엇에 반대하는지를 먼저 적는다.**

이것을 자유 서술로 두면 범용 프로세스가 되지 않는다. 그래서 **표기 형식을 고정한다.**

#### 반대 대상 표기 형식

```
[층위] · [지배 규범 한 줄] → [우리가 어기는 지점] · [강도]
```

**층위 — 6개 중 선택** (직관적 선택을 위해 목록을 닫아둔다)

| 코드 | 층위 | 뜻 | 검증 질문 |
|---|---|---|---|
| `CAT` | 카테고리 관습 | 그 업종이 다 그렇게 하는 것 | 같은 업종 3곳이 그렇게 하는가 |
| `COMP` | 경쟁사 | 특정 경쟁사의 화법 | 그 경쟁사 자산에서 확인되는가 |
| `SELF` | 우리 과거 | 이전 시즌·버전의 우리 자신 | 우리 과거 산출물에 있는가 |
| `PLAT` | 플랫폼 기본 | OS·프레임워크의 기본 표정 | 기본 컴포넌트가 그렇게 생겼는가 |
| `ISM` | 사조 규범 | 카탈로그의 특정 사조 | `ISM-*` ID로 지정 가능한가 |
| `EXP` | 타겟의 기대 | 타겟이 예상하는 것 | 타겟이 말로 설명할 수 있는가 |

**강도 — 3단계**

| 코드 | 강도 | 뜻 |
|---|---|---|
| `이탈` | deviate | 규범을 따르되 한 축만 비틀어 다르게 한다 |
| `역전` | invert | 규범의 값을 뒤집는다 |
| `거부` | reject | 규범 자체를 쓰지 않는다 |

**핵심 제약 — 반대 대상은 주장이 아니라 관찰이어야 한다.**
층위마다 붙은 검증 질문에 **실례 2개 이상**으로 답하지 못하면 그것은 반대 대상이 아니다. 실례가 없는 반대는 상상 속의 적이고, 그 적을 공격한 조형은 N1(차별을 위한 차별)로 판정한다.

#### 작성 예

```
CAT · 국내 보험 브랜딩은 신뢰를 파랑·세리프·가족 사진으로 표기한다
      → 신뢰를 여백과 단색 하나로만 표기한다 · 역전
      실례: A사 2024 캠페인, B사 브랜드 사이트, C사 앱 온보딩
```

```
PLAT · 미니앱 기본 컴포넌트는 모든 카드에 그림자와 라운드를 준다
      → 그림자를 제거하고 경계를 선 하나로만 표기한다 · 이탈
      실례: 플랫폼 기본 카드, 동일 플랫폼 상위 노출 미니앱 2건
```

```
SELF · 우리는 전 세대 포용을 멀티컬러로 표기해 왔다
      → 노랑 단일색과 타입 스케일 폭으로 표기한다 · 이탈
      실례: 2025 자사 서비스 2건
```

반대 대상이 없는 프로젝트도 정상이다 — 그 경우 이 칸을 `없음`으로 적고 실험적 조형을 쓰지 않는다. **비워두는 것과 `없음`으로 적는 것은 다르다.**

## 5. Tunnel Effect — 터널

### 5.1 정의

여행에서 얻은 것들을 들고 **어두운 터널에 진입**한다. 터널 안에서 타겟·브랜드 특성과 소비자 이용(UX) 관점을 **레이어링**해, **밝은 출구**를 찾는다.

### 5.2 터널이 어두운 이유

진입 시점에 정답이 없기 때문이다. 사조를 몇 개 골랐다는 것만으로는 아무것도 결정되지 않는다. 터널 안의 작업은 **레이어를 겹쳐 정답의 범위를 좁히는 일**이고, 레이어가 겹칠수록 밝아진다.

레이어 3종:

| 레이어 | 질문 | 산출 |
|---|---|---|
| ① 타겟 | 누가 보는가 | 연령·맥락·기기·숙련도 |
| ② 브랜드 특성 | 무엇이 이 브랜드만의 것인가 | 톤, 금지 사항, 경쟁사와 갈리는 지점. `[제안]` 여기서 브랜드는 **클라이언트(서비스)의 브랜드**다 — 더프롬이 아니다(§1.1) |
| ③ 소비자 이용(UX) | 실제로 어떻게 쓰는가 · `[제안]` 그 순간 무엇을 원하는가 | 관성적 행태, 이탈 지점, 반복 사용 빈도 · `[제안]` **핵심 순간의 동기와 감정** — 사용자가 이 화면에서 얻고 싶은 것 |

세 레이어를 다 겹치지 않은 상태로 출구를 주장하는 것은 터널을 통과한 것이 아니라 터널을 우회한 것이다.

## 6. 출구 판단 기준 — 게이트

출구는 다음 **일곱 조건이 동시에** 성립하는 순간이다. `[제안]` (v0.2까지 다섯 조건. v0.3 G4 재정의·G6 신설, v0.4 G7 신설) 하나라도 불충족이면 터널에 남는다.

| # | 조건 | 불충족 시 |
|---|---|---|
| **G1** | 기성을 답습하지 않았다 | 레퍼런스 조합에 그침 → 여행 재실행 |
| **G2** | 우리만의 색(크리에이티브 메타포, UI/UX)이 있다 | 근본 없는 하이브리드 → 믹스 재검토 |
| **G3** | 사용자의 관성적 행태를 해치지 않는다 | 사용성 실패 → 조형 후퇴 |
| **G4** | `[제안]` **익숙한 UI 패턴에 새로운 해석을 준다** (v0.2: 시각적 새로움을 준다) | 패턴이 읽히지 않음 → 조형 후퇴 / 해석이 통상과 같음 또는 사용자에게 주는 것이 없음 → 패턴 재해석 (→ §6.4) |
| **G5** | 자메뷰 관점의 해석이 타겟에게 **통렬하게** 작동한다 | 해석이 타겟에게 닿지 않음 → 레이어 ① 재검토 |
| **G6** | `[제안]` **컨셉이 비주얼과 작동성 양쪽에 체화되어 있다** | 한쪽에만 있음 → 패턴 재해석 / 양쪽 모두 없음 → 메타포 재도출 (→ §6.5) |
| **G7** | `[제안]` **조형이 완성되어 있다** — 위계·균형·강조·여백·타이포가 근거 있게 작동하고, 더프롬이 포트폴리오에 올릴 수준이다 | 구조 문제 → 조형 재설계 (S3) / 디테일 문제 → 실체화 재작업 (S5) (→ §6.6) |

### 6.1 G3과 G4는 서로 당긴다 — 이게 이 방법론의 핵심 긴장

새로움은 관성을 건드려서 얻어진다. 그런데 관성을 해치면 안 된다. 이 둘을 동시에 만족시키는 방법은 하나뿐이다:

> **관성은 구조에서 지키고, 새로움은 해석에서 만든다.**

- 지킬 것 — 탐색 구조, 버튼이 버튼처럼 보이는 것, 읽기 순서, 되돌아가기, 접근성
- 밀 것 — 크리에이티브 메타포, 톤, 모션의 성격, 타입의 표정, 컬러의 해석

브루탈리즘이 "플랫폼 기본값을 부끄러워하지 마라"로 도달한 결론이 G3이고, 멤피스가 "제품의 성격은 기능과 동등한 설계 대상"으로 도달한 결론이 G4다. 둘은 대립하지 않는다 — 적용 영역이 다르다.

`[제안]` **G4는 이 문장의 판정 형식이다.** v0.2의 G4("시각적 새로움을 준다")는 새로움이 어디서 오는지를 묻지 않아서, 장식과 디테일로 새로움을 사는 길을 열어두었다. v0.3의 G4는 새로움의 출처를 **해석**으로 못 박는다 — 구조(패턴)는 지키고, 그 패턴을 보는 관점을 바꾼다.

### 6.2 자메뷰(jamais vu)에 대하여

데자뷰가 낯선 것을 익숙하게 느끼는 것이라면, 자메뷰는 **익숙한 것을 처음 보는 것처럼 느끼는 것**이다.

이것이 출구 기준의 핵심인 이유: 우리는 사용자에게 낯선 구조를 주지 않는다(G3). 우리가 주는 것은 **익숙한 구조를 처음 보는 것처럼 만드는 해석**이다. 그래서 G5는 "새로운가"가 아니라 **"익숙한 것이 새로 보이는가"**를 묻는다.

### 6.3 통렬함의 판정 — 2단 판정

G5의 "통렬하게"는 정도가 아니라 **방향**의 기준이다. 타겟이 "예쁘네"라고 반응하면 통렬하지 않다. **"어, 이거"**라고 반응하면 통렬하다. 전자는 감상이고 후자는 인식의 전환이다.

판정은 두 단으로 한다. **1차는 필수, 2차는 가능하면.**

| 단 | 판정자 | 지위 | 조건 |
|---|---|---|---|
| **1차** | 사내 테스트 | **필수** | **해당 프로젝트에 참여하지 않은 사내 인원** 3명 이상 |
| **2차** | 외부 타겟 | 가능하면 (가장 이상적) | 타겟 조건에 해당하는 외부인. S0에서 이름을 지정 |

**1차의 핵심 조건은 '사내'가 아니라 '비참여'다.** 만든 사람은 이미 해석을 알고 있어서 자메뷰가 성립하지 않는다. 프로젝트를 모르는 사람에게 처음 보여주는 것이 판정의 최소 요건이다.

**판정 방법** — 설명하지 않고 보여주고, 첫 반응을 그대로 기록한다.

| 반응 유형 | 판정 |
|---|---|
| "어, 이거" / "이건 뭐지" / 되돌아와 다시 봄 | **통과** — 인식의 전환 |
| "예쁘네" / "깔끔하다" / "좋네요" | **실패** — 감상에 머묾 |
| "○○ 같다" (다른 브랜드·사조를 지명) | **실패** — G1 답습 신호. S1로 회귀 |
| 무반응 / 넘어감 | **실패** — G4 신호. 패턴 재해석 `[제안]` (v0.2: 대비·강조 재설계) |

**금지**: 판정 전에 컨셉을 설명하지 않는다. 설명하고 받은 반응은 판정이 아니라 동의다.

2차를 수행하지 못한 채 통과시킨 경우, `S4_판정.md`에 **"1차만 수행"**을 기록한다. 기록 없이 넘어가면 나중에 판정 강도를 알 수 없다.

### 6.4 G4의 판정 — 두 조건 `[제안]`

G4는 세 조건을 **모두** 통과해야 한다. (v0.3은 ①②의 두 조건. `[제안]` v0.4에서 ③ 추가)

| # | 조건 | 판정 질문 |
|---|---|---|
| ① | **패턴 가독성** | 한눈에 무엇이고 어떻게 쓰는지 읽히는가 |
| ② | **해석의 차별** | 통상적 해석과 다른 관점인가 |
| ③ | `[제안]` **사용자 가치** | 그 다름이 사용자에게 **무엇을 더 주는가** — 더 잘 이해하게, 더 깊이 느끼게, 더 쉽게 행동하게 중 하나 이상 |

**효익은 보이게 만들어야 판정된다.** "이해가 쉬워진다"는 주장이 아니라, 화면에서 무엇이 **보이게** 되어 사용자의 과업(이해·비교·결정·공유)이 빨라지는지를 **효익 지표**로 적는다(→ L1 S2 효익 시각화). 예: "3초 안에 내 위치를 안다", "다른 사람과 어디가 다른지 한 화면에서 비교한다". `[제안]` v0.5

**③이 없으면 다름은 만든 사람의 것이다.** 해석이 통상과 다르기만 하고 사용자가 얻는 것이 없다면, 그 재해석은 N1(차별을 위한 차별)과 같은 자리에 있다. ③은 L1 S2 재해석 표의 `사용자가 얻는 것` 칸으로 판정한다.

> **새로움은 장식·디테일이 아니라 UI/UX 해석과 접근 방식에서 나온다.**

**②의 비교 대상은 기록되어 있어야 한다.** 통상적 해석은 L1 S2 패턴 재해석에서 반대 대상 표기 형식(§4.2)으로 적는다. 기록이 없으면 "무엇과 다른가"에 답할 수 없으므로 ②는 판정 불가 — 실패로 본다.

**②의 점검 — 걷어내기.** 장식·디테일(질감·그림자·일러스트·장식적 모션)을 걷어낸 상태에서도 해석의 차별이 성립하는지 본다. 걷어내자 통상적 해석과 같아진다면, 새로움은 해석이 아니라 장식에 있었다.

| 결과 | 진단 | 회귀 |
|---|---|---|
| ①만 통과 | 기성 패턴을 그대로 썼다 — 안전하고 지루함 | → 패턴 재해석 (L1 S2) |
| ②만 통과 | 새롭지만 읽히지 않는다 | → 조형 후퇴 (L1 S3) |
| 둘 다 실패 | 해석도 가독성도 없다 | → 패턴 재해석부터 |
| ③ 실패 | 다르지만 사용자가 얻는 것이 없다 | → 패턴 재해석 (L1 S2 — 레이어 ③의 동기·감정부터) |

**G3과 G4 ①의 구분.** 둘 다 "쓸 수 있는가"처럼 보이지만 묻는 것이 다르다.

| | 묻는 것 | 시점 |
|---|---|---|
| G3 | **행태** — 사용자가 익숙한 방식대로 과업을 끝낼 수 있는가 | 사용 중 |
| G4 ① | **인지** — 처음 본 순간 이것이 무엇이고 어떻게 쓰는지 읽히는가 | 첫 대면 |

### 6.5 G6 컨셉 체화 — 판정 쌍 `[제안]`

G2가 "우리만의 색(크리에이티브 메타포)이 **있는가**"를 묻는다면, G6은 그 메타포가 **비주얼과 작동성 양쪽에 들어갔는가**를 묻는다. 컨셉이 한쪽에만 있으면 그것은 체화가 아니라 겉옷이다.

| # | 판정 | 방법 | 판정 질문 |
|---|---|---|---|
| ① | **작동** | 무채색 와이어프레임 — 색·이미지·질감을 제거하고 인터랙션·모션은 유지한 채 조작해 본다 | 작동만으로 컨셉이 느껴지는가 |
| ② | **정지** | 정지 화면 — 인터랙션·모션을 멈춘 화면만 본다 | 정지 화면만으로 컨셉이 읽히는가 |

**둘 다 통과해야 한다.**

| 결과 | 진단 | 회귀 |
|---|---|---|
| ①만 통과 | 비주얼이 컨셉과 무관한 스킨이다 | → 패턴 재해석 (L1 S2) |
| ②만 통과 | 작동이 기본 조합이고, 컨셉은 표면에만 있다 (→ §7.3-5) | → 패턴 재해석 (L1 S2) |
| 둘 다 실패 | 메타포가 설계에 들어가지 않았다 | → 메타포 재도출 (L1 S2 레이어 3종부터) |

**G5와의 차이 — 판정자.** G5는 컨셉을 모르는 사람이 판정한다(자메뷰는 처음 보는 사람에게만 성립한다). G6은 **컨셉을 아는 사람이 판정한다.** 묻는 것이 "처음 보는 느낌"이 아니라 "컨셉이 들어 있는가"이기 때문이다.

### 6.6 G7 조형 완성도 `[제안]`

G1~G6은 **무엇을 말하는가**(답습·메타포·관성·해석·체화)를 판정한다. **얼마나 잘 만들었는가**는 판정하지 않는다. 그래서 해석은 새롭지만 조형이 약한 결과물이 모든 게이트를 통과할 수 있었다. G7이 그 빈자리를 채운다.

판정 항목은 Knowhow Book Lv.1의 원칙에서 가져온다(→ L2 B-0 12원칙).

| # | 항목 | 판정 질문 | 참조 |
|---|---|---|---|
| ① | **위계** | 화면마다 1순위 정보가 3초 안에 읽히는가. 2·3순위가 그 다음 순서로 읽히는가 | `LAY-HIER` `COMP-*` 원문 "구도는 일종의 시각적 위계 시스템이다" |
| ② | **강조** | 강조점이 화면당 하나인가. 강조가 배경·여백·대비로 만들어졌는가 | `EMP-*` 원문 "강조는 단독으로 존재하지 않으며" |
| ③ | **균형·비율** | 시각적 무게가 의도대로 분산되었는가. 비율이 ID로 설명되는가 | `BAL-*` `RATIO-*` |
| ④ | **대비·리듬** | 대비가 평면적이지도 과하지도 않은가. 반복이 단조롭지 않은가 | `CON-*` `RHY-*` · §7.2 |
| ⑤ | **여백** | 여백에 근거가 있는가 — 근거 없는 여백은 정보 부족이다 | `EMP-SPACE` · §7.2 |
| ⑥ | **타이포** | 타입 위계가 선명한가. 본문 가독성, 행간, 한 줄 길이, 한글 조판이 정돈되었는가 | `TYPE-*` |
| ⑦ | **디테일** | 앵글·빛·질감의 층위마다 의도가 있는가 — 양이 아니라 의도. `[제안]` **담백함과 미완성의 구분**: 디테일을 뺀 이유를 한 줄로 말할 수 있는가. 말할 수 없으면 비어 있는 것이다 | B-15 |
| ⑧ | **포트폴리오 기준** | 더프롬 시니어 디자이너가 이 결과물을 **자기 포트폴리오에 올리겠는가** | 사람 판정 |

**①~⑦은 Claude가 예비 판정할 수 있다** — 화면 캡처를 보고 항목마다 근거를 적는다. **⑧과 최종 판정은 사람이 한다.** ⑧은 나머지 항목이 모두 통과해도 실패할 수 있다. 그때는 무엇이 부족한지를 ①~⑦의 언어로 다시 적는다.

| 결과 | 회귀 |
|---|---|
| ①③ 실패 (구조) | → 조형 재설계 (L1 S3 구도·레이아웃) |
| ②④⑤⑥⑦ 실패 (표현) | → 실체화 재작업 (L1 S5) |
| ⑧만 실패 | → 부족한 것을 ①~⑦로 번역한 뒤 해당 단계로 |

### 6.7 판단이 부딪힐 때 `[제안]`

| 부딪히는 것 | 우선 |
|---|---|
| 사용자 경험(G3·G4③) ↔ 방법론의 형식 (1U 규칙·정렬 규칙·반대 대상 형식) | **사용자 경험.** 형식을 바꾸고 근거를 기록한다 |
| 조형 완성도(G7) ↔ 1U 값·기본값 | **조형.** 1U 값을 다시 정한다. 조형을 1U에 맞추지 않는다 |
| 조형 완성도(G7) ↔ 해석의 차별(G4②) | **둘 다.** 한쪽을 포기하지 않는다 — 해석은 유지하고 조형을 다시 한다. 해석 자체가 좋은 조형을 막는다면 그 해석은 약한 해석이다 → S2 |

### 6.8 컨셉의 옳고 그름을 먼저 판정한다 — 비용 원칙 `[제안]`

컨셉과 메타포가 틀렸는데 시안·시스템·실체화까지 진행하면, 그 비용은 전부 버려진다. 게이트 G1~G7은 산출물을 거의 다 만든 뒤(S4)에 판정하므로, **컨셉의 옳고 그름은 그보다 훨씬 앞에서, 가장 싼 형태로** 판정한다.

> **비싼 단계는 판정 뒤에 둔다.**

| 비용 | 단계 | 이 단계에서 만드는 것 |
|---|---|---|
| 낮음 | S0~S2 전반 | 문장·표·핵심 화면 러프 1장 |
| — | **컨셉 판정 (C 게이트, L1 S2)** | 사람이 go / 수정 / 중단을 정한다 |
| 중간 | S2 후반·S3 | A/B 시안, 시스템 |
| 높음 | S4~S5 | 완성 시안, 상태, 핸드오프 |

C 게이트에서 판정하는 것은 **컨셉 한 문장 · 메타포 · 효익 가설 · 효익 시각화 러프**다. 아름다운지를 묻지 않는다. **맞는 방향인지, 사용자에게 무엇을 주는지**를 묻는다. G2(우리만의 색)의 사전 판정을 겸한다.

## 7. 하지 않는 것

### 7.1 절대 하지 않는 것

| # | 금지 | 근거 |
|---|---|---|
| **N1** | **차별을 위한 차별** | 차별화 자체를 목적으로 한 조형은 차별로 인정하지 않는다. 다름은 결과여야 하고 목표일 수 없다. |
| **N2** | 근거를 설명할 수 없는 조형 | 장식은 금지 대상이 아니라 **입증 대상**이다(→ `ISM-BAUHAUS`). 입증되지 않은 것은 삭제한다. |
| **N3** | 사용자의 관성적 행태를 해치는 실험 | G3 위반. 실험은 해석 층에서만 한다. |
| **N4** | 접근성을 실험의 비용으로 지불하기 | 대비, 초점 순서, 읽기 순서, 타깃 크기는 조형 실험의 면제 항목이 아니다. |

| **N7** | `[제안]` **더프롬을 클라이언트 결과물에 새기기** | 1U 형상(정사각형 단위·막대 쌓기·3U/2U/1U 비례), 더프롬 브랜드 컬러, "나로부터" 서사를 클라이언트 결과물의 모티프·메타포·팔레트로 쓰지 않는다. 철학은 판단의 방법이다(§1.1, §2.2.4). 자기 브랜드를 남의 결과물에 새기는 것은 N6의 가장 가까운 변형이다 — 우리 자신을 사조로 인용하는 것이다. |

### 7.2 경계하는 것 — 과잉의 경계선

L2 카탈로그가 각 항목에서 반복적으로 경고하는 것을 규범으로 올린다.

| 대상 | 경계선 |
|---|---|
| 대비 | 없으면 평면적·무미건조, 지나치면 혼란·시선 분산 |
| 색상 대비 | 너무 강하면 눈이 피로하고 정보가 안 읽힌다 |
| 강조색 | 너무 많이 쓰면 **강조 효과 자체가 사라진다** |
| 반복 | 지나치면 단조롭고 지루하다 |
| 무작위 | 과도하면 산만하고 혼란스럽다 |
| 그리드 | 감옥이 되면 의도적 파괴(브레이크아웃)를 잃는다 |
| 중립성 | 무표정과 혼동하면 브랜드가 없는 화면이 된다 |
| 여백 | 근거 없는 여백은 미학이 아니라 **정보 부족**이다 |
| 디테일 | 양으로 접근하면 실패한다 — 층위별 의도의 명확성이 기준이다 |

### 7.3 태도로서 경계하는 것

1. **트렌드 답습** — 트렌드 추종 자체가 신뢰를 잃는 요인이다. 탄탄한 이해를 바탕으로 한 결정이 신뢰를 얻는다.
2. **원칙 없는 파괴** — 기본 원칙을 명확히 알고 있어야만 깨뜨리고 비틀 수 있다. 선행 조건 없는 파괴는 파괴로 인정하지 않는다.
3. **도구 의존** — 도구는 끊임없이 바뀌지만 디자인 원칙은 변하지 않는다.
4. **오리엔탈리즘·클리셰** — 일본·한국 미학을 다룰 때 특히. 오방색을 무맥락 5색 팔레트로, 한지 텍스처를 '한국성' 스티커로 쓰는 것은 전통의 계승이 아니라 관광 브로슈어의 복제다(→ `ISM-KR` 전이 시 위험).
5. `[제안]` **플랫폼 컴포넌트로 끝내기** — 플랫폼 컴포넌트는 **구조층의 관성으로 수용할 수 있다**(G3, → `ISM-BRUTAL` "기본값을 그대로 존중"). 그러나 **핵심 경험을 플랫폼 컴포넌트 조합만으로 끝내지 않는다.** 핵심 경험까지 기본 조합이면 해석이 들어갈 자리가 없고, G2·G4·G6이 성립하지 않는다. 구분의 기준은 "어디까지가 구조층인가"다 — 탐색·입력·시스템 피드백은 수용하고, 그 서비스의 핵심 순간은 재해석 대상으로 삼는다(→ L1 S2 패턴 재해석).

## 8. 이 방법론의 층 구조

```
L0  CORE       이 문서 — 철학·1U·출구 기준·금지
     │
     ├─ 판단 기준을 제공
     ▼
L1  PIPELINE   실행 절차 — 단계·입력·산출·게이트
     │  └ QNA      질문 노드 — 공백이 감지될 때 사용자에게 묻는 형식   [제안]
     │
     ├─ 선택지를 조회
     ▼
L2  CATALOG    기성의 관점 — 사조·구도·비율·질감·UI 패턴 (ID로 참조)
```

**변경 규칙**
- L2는 자유롭게 추가한다. 사조를 더 넣거나 항목을 깊게 하는 것은 L0·L1에 영향을 주지 않는다.
- L1은 프로세스가 실제로 바뀔 때만 고친다. `[제안]` QNA(`3_QNA_질문노드.md`)는 L1의 부속이며 L1과 같은 규칙으로 고친다.
- **L0은 합의를 거쳐 고친다.** 개정 이력을 반드시 남긴다.

## 9. Claude와 사람의 역할 `[제안]`

이 방법론은 Claude 스킬로 실행된다. 누가 무엇을 하는지가 흐리면 두 가지 사고가 난다 — **Claude가 판정을 대신하거나, 증거를 지어낸다.** 둘 다 이 방법론의 판단을 무력화한다(§1: "누가, 무엇을 근거로 그렇게 판단했는가"가 기록되어야 한다). 그래서 역할을 셋으로 나눈다.

### 9.1 세 구분

| 구분 | 대상 | Claude가 하는 일 |
|---|---|---|
| **연산** — Claude 수행 | S0 초안, S1 사조 취사, A3 판정, S2 4축 조합, S3 1U 파생, S5 실체화, G7 ①~⑦ 자기 비평 | 수행하고 근거를 기록한다 |
| **증거** — 검색 또는 질문 | 반대 대상 실례(A4·패턴 재해석의 통상적 해석), G1 비교 레퍼런스 | 검색하거나 사용자에게 묻는다. **절대 생성하지 않는다.** 없으면 삭제하거나 `없음`으로 적는다 |
| **판정** — 사람 | G2 최종, G5 전체, G6 최종, `[제안]` G7 최종(⑧ 포함) | **판정 키트**만 준비한다 |

### 9.2 증거는 생성하지 않는다

실례 없는 반대는 상상 속의 적이다(§4.2). 지어낸 실례는 그보다 나쁘다 — 상상 속의 적에 가짜 증거를 붙여 N1 판정을 우회한다. 따라서:

- 모든 실례에는 **출처**를 붙인다 — 검색 결과의 주소, 또는 `사용자 제공`
- 2건을 채우지 못하면 그 반대 대상은 삭제한다. 반대 대상이 하나도 남지 않으면 `없음`으로 적는다
- "~할 것이다", "일반적으로 ~한다"는 실례가 아니다

### 9.3 예비 판정

Claude가 내린 **G1·G3·G4·G6·G7** 판정은 모두 `예비 판정`으로 표기한다. 예비 판정은 다음 단계의 진행을 막지 않지만, `S4_판정.md`에서 사람이 확정하기 전까지 출구 통과로 기록하지 않는다.
