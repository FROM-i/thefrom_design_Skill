# 다른 AI에서 thefrom-ux 쓰기 — ChatGPT · Gemini · 기타

thefrom-ux는 Claude 스킬로 만들었지만, 방법론 자체는 문서입니다. **지침 한 장 + 지식 파일 8개**만 있으면 ChatGPT, Gemini 등 다른 AI에서도 같은 방식으로 쓸 수 있습니다.

```
portable/
├── instructions.md        ← 지침 (약 2,800자) — AI의 "지침·Instructions" 칸에 붙여넣기
└── knowledge/             ← 지식 파일 8개 — AI의 "지식·Knowledge" 칸에 업로드
    ├── core.md            철학·1U·게이트 G1~G7·금지
    ├── pipeline.md        S0~S5 절차·산출물 양식
    ├── qna.md             질문 노드
    ├── catalog-ism.md     사조 16
    ├── catalog-form.md    조형 어휘 (Knowhow Book)
    ├── catalog-pattern.md UI 패턴·시각화·모션·상태
    ├── proto-base.html    375px 프로토타입 베이스
    └── brief-template.md  브리프 양식
```

> `knowledge/`는 `method/`에서 자동 생성됩니다. 직접 고치지 말고, 방법론을 고친 뒤 `python3 scripts/build_references.py`를 실행하세요.

---

## 1. 어디서 어떻게 — 한눈에

| 도구 | 방식 | 준비물 | 비고 |
|---|---|---|---|
| **ChatGPT — 맞춤 GPT** | 지침 + 지식 파일 | `instructions.md` + `knowledge/` 8개 | 개인 유료 플랜 이상. 가장 쉬운 방법 |
| **ChatGPT — Skills** | 스킬 폴더 그대로 | `plugins/thefrom-ux/skills/thefrom-ux/` | ChatGPT Work(업무용 워크스페이스) 베타. 관리자가 켜야 함. Claude 스킬과 같은 SKILL.md 표준 |
| **Codex** (OpenAI 코딩 에이전트) | 스킬 폴더 그대로 | 위와 같음 | `.agents/skills/thefrom-ux/`에 복사 |
| **Gemini — Gem** | 지침 + 지식 파일 | `instructions.md` + `knowledge/` 8개 | Google Drive에서 파일을 추가하면 원본 수정이 자동 반영 |
| **기타 AI / API** | 시스템 프롬프트 + 첨부 | 위와 같음 | 파일 첨부가 안 되면 `core.md`와 `pipeline.md`만이라도 붙인다 |

## 2. ChatGPT 맞춤 GPT 만들기

1. ChatGPT 왼쪽 **GPT 탐색 → 만들기** → **구성(Configure)** 탭
2. **이름**: `더프롬 UX` · **설명**: `더프롬 방법론으로 화면을 설계하고 375px 프로토타입을 만든다`
3. **지침(Instructions)**: `portable/instructions.md` 내용을 **전부** 붙여넣기
4. **지식(Knowledge)**: `portable/knowledge/`의 파일 8개 업로드
5. **기능(Capabilities)**: **웹 검색 켜기**(반대 대상 실례·비교 레퍼런스를 찾는 데 필요), **코드 인터프리터 켜기**(파일 정리·검산), **캔버스 켜기**(HTML 미리보기)
6. **대화 시작 문구** 예시
   - `이 브리프로 S0부터 시작해줘` (브리프 붙여넣기)
   - `C 게이트 판정 재료만 먼저 만들어줘`
   - `이 화면 캡처를 G7 기준으로 비평해줘`
7. 공유: 우측 상단 **공유** → 조직 내 링크 공유

## 3. ChatGPT Skills · Codex에 넣기

ChatGPT Skills와 Codex는 Claude와 같은 **SKILL.md 표준(Agent Skills)**을 따릅니다. 스킬 폴더를 그대로 씁니다.

- **ChatGPT Skills**: 워크스페이스 관리자가 설정에서 Skills를 켠 뒤, `plugins/thefrom-ux/skills/thefrom-ux/` 폴더를 zip으로 묶어 업로드합니다. 대화에서 `@thefrom-ux`로 부르거나 관련 요청을 하면 자동으로 붙습니다.
- **Codex**: 프로젝트 폴더의 `.agents/skills/thefrom-ux/` 또는 내 홈의 `~/.agents/skills/thefrom-ux/`에 스킬 폴더를 복사합니다. 이 경우 Claude와 거의 같이 동작합니다 — `scripts/shoot.py`로 캡처 루프까지 돌 수 있습니다(Playwright 필요).

## 4. Gemini Gem 만들기

1. gemini.google.com → 왼쪽 **Gem 관리자 → 새 Gem**
2. **이름**: `더프롬 UX`
3. **요청 사항(Instructions)**: `portable/instructions.md` 내용을 전부 붙여넣기. "Gemini로 요청 사항 확장" 버튼은 누르지 않는다 — 규칙이 바뀐다.
4. **지식**: **파일 추가** → `knowledge/` 8개. 회사 Google Drive에 `knowledge/` 폴더를 두고 Drive에서 추가하면, 파일을 고칠 때 Gem에도 반영됩니다.
5. 저장 → **공유**로 팀에 링크 전달. 받은 사람은 한 번 열어야 내 Gem 목록에 생깁니다.

## 5. 기타 AI · API

- 시스템 프롬프트에 `instructions.md`를 넣고, 파일 첨부나 검색(RAG)으로 `knowledge/`를 제공합니다.
- 첨부할 수 있는 양이 적으면 **우선순위**: `core.md` → `pipeline.md` → `catalog-pattern.md` → `qna.md` → 나머지.

## 6. 첫 요청 — 브리프부터

> **"더프롬처럼 만들어줘"만으로는 아무것도 나오지 않습니다.** 지침에 브리프 게이트가 들어 있어서, 필수 항목(★1 무엇을 · ★2 누구에게 · ★3 핵심 순간)이 비면 AI는 질문부터 합니다. 이것이 정상 동작입니다.
>
> 브리프는 저장소의 **`tools/brief-editor.html`**(브라우저로 열어 쓰고 .md 저장)로 쓰거나, `knowledge/brief-template.md` 양식을 채웁니다. 만든 .md를 대화에 첨부하세요.

```
[브리프 붙여넣기 — ★1~★6을 채운 것]

더프롬 방식으로 진행해줘.
- 범위: (예) 진입 · 결과 · 커뮤니티 3화면
- 브랜드: (클라이언트 브랜드 / 없음)
- C 게이트에서 멈춰줘   ← 기본. 끝까지 보고 싶으면 "끝까지 진행"
```

단계별로 따로 부를 수도 있습니다.

| 하고 싶은 것 | 요청 |
|---|---|
| 컨셉 방향만 싸게 보기 | `C 게이트 판정 재료까지만 만들어줘` |
| A/B 비교 | `A 시스템 주도, B 경험 주도로 시안 만들고 명분·효익 표로 비교해줘` |
| 시안 비평 | `(캡처 첨부) 이 화면을 G7 ①~⑦로 비평하고 가장 약한 3곳을 고쳐줘` |
| 타입 스케일 | `1U 8px로 S3 타입 스케일 표 만들어줘 (0.25U 조건 지켜서)` |
| 반대 대상 찾기 | `결과 화면의 통상적 해석을 반대 대상 형식으로, 실례 2건 검색해서 출처와 함께` |

## 7. Claude와 다른 점 — 알아두면 결과가 좋아집니다

| 항목 | Claude (스킬) | ChatGPT / Gemini (지침 + 지식) | 보완 방법 |
|---|---|---|---|
| 참조 파일 읽기 | 단계마다 필요한 파일을 통째로 읽음 | 지식 파일을 **검색해서 일부만** 읽음 | 요청에 절이나 ID를 적는다 — "core.md §6.6 G7 기준으로" |
| 크리틱 루프 캡처 | `shoot.py`로 자동 캡처하고 스스로 봄 | 대개 불가 | **캡처를 직접 첨부**하고 비평을 요청한다. 캔버스 미리보기를 캡처해도 된다 |
| 프로토타입 | 파일로 저장 | 캔버스에서 HTML 미리보기(지원되는 경우) | 코드를 `.html`로 저장해 브라우저에서 연다 |
| 증거 검색 | 검색 도구 사용 | **웹 검색을 켜야** 함 | 꺼져 있으면 실례는 전부 `없음`이 된다 — 정상 동작 |
| 긴 작업 | S0~S5 한 번에 | 대화가 길어지면 앞 내용을 잊기 쉬움 | **단계마다 끊어서** 요청하고, 이전 S 문서를 다시 붙인다 |

## 8. 결과 점검 — 6가지만 보세요

어떤 AI에서 돌리든, 다음 중 하나라도 걸리면 지침이 제대로 적용되지 않은 것입니다.

- [ ] 결과 화면에 **정사각형 단위·막대 쌓기·더프롬 컬러**가 보인다 → "N7 위반, 클라이언트 브랜드로 다시"
- [ ] 반대 대상 **실례에 출처가 없다** → "출처 없는 실례는 지우고 `없음`으로"
- [ ] 판정에 `예비 판정` 표기 없이 **"통과"라고 확정**한다 → "C·G2·G5·G6·G7 최종은 사람이 한다"
- [ ] C 게이트에서 멈추지 않고 **완성 시안까지** 갔다 → (끝까지 진행을 요청하지 않았다면) 비용 원칙 위반
- [ ] 재해석에 **사용자가 얻는 것·효익 지표가 비어** 있다 → "G4 ③ 채워줘"
- [ ] 브리프가 부실한데 **질문 없이 바로 시안**을 만들었다 → "브리프 게이트부터 — ★1~3 인터뷰해줘"

## 9. 업데이트

방법론이 바뀌면 이 저장소의 `portable/`가 함께 갱신됩니다.

- **맞춤 GPT**: 지침을 다시 붙여넣고, 지식 파일 8개를 지웠다가 다시 올립니다.
- **Gem**: Drive에서 추가했다면 자동 반영. 기기에서 올렸다면 다시 올립니다.
- **ChatGPT Skills · Codex**: 스킬 폴더를 새것으로 바꿉니다.
