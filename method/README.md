| 파일 | 계층 | 성격 | 언제 보는가 | 변경 빈도 |

---

## 왜 한 파일이 아닌가

1. **변경 주기가 다르다.** 카탈로그는 계속 늘고 코어는 거의 안 바뀐다. 한 파일이면 두 종류의 변경이 섞여 코어가 조용히 흔들려도 아무도 눈치채지 못한다.
2. **용도가 다르다.** 카탈로그는 **조회**, 파이프라인은 **실행**. 실행 문서에 조회 내용이 섞이면 읽다가 길을 잃는다.
3. **스킬화하려면 분리가 필수다.** SKILL.md는 짧아야 하고 참조 자료는 `references/`로 빠진다. 파이프라인이 ID로 참조하므로 카탈로그가 세 배로 커져도 파이프라인은 한 줄도 안 바뀐다.
4. **IP 등급이 다르다.** 카탈로그는 대부분 공개 지식의 정리라 신입 교육·외부 공유가 가능하다. L0의 1U와 출구 판단 기준은 더프롬의 코어다.

## 처음 쓰는 사람에게

1. **`0_CORE`를 한 번 읽는다.** 15분. 특히 §4(airplane) §5(tunnel) §6(출구 게이트) §7(하지 않는 것) §9(Claude와 사람의 역할).
2. **프로젝트를 시작할 때 `1_PIPELINE`을 연다.** S0부터 순서대로. 각 단계의 산출물을 실제로 남긴다.
3. **`2_CATALOG`는 통독하지 않는다.** 파이프라인이 지시하는 ID만 찾아 본다.
4. **`3_QNA`는 막혔을 때 연다.** 단계 표의 QnA 행이 지시하는 노드만 본다.

## 핸드오프에서 인용하는 방법

프로젝트 문서에서는 ID로 쓴다. 카탈로그 내용을 복사하지 않는다.

```
키비주얼: COMP-DIA + LIGHT-LOKEY + LIGHT-DSIDE + TEX-MATTE
근거: ISM-JP(그림자는 독립적 매체) — 谷崎 원리의 기술적 구현
비율: RATIO-169
정렬 예외: 없음
```

### v0.5에서 바뀐 것 — 파일럿 2회차의 교훈

2회차 결과는 1U 상징화는 벗어났지만 **컨셉 아이디어에 치우쳤다** — 메타포(인물 기사)가 화면을 정했고, 사용자가 얻는 것이 시각적으로 드러나지 않았다. 그리고 컨셉의 옳고 그름을 판정하지 않은 채 완성 시안까지 만들어 **비용 위험**이 있었다.

| 문제 | 고친 것 |
|---|---|
| A/B가 같은 방향의 변주였다 | **A 시스템 주도(1U 접근 — 대조군)** / **B 경험 주도(컴포넌트 자유, 구조·포인트·디테일에 방법론)** + 명분·효익 표. 효익 칸이 빈 결정은 개살구 |
| 효익이 보이지 않았다 | **효익 시각화** — 과업 → 보이게 할 것 → `VIZ-*` → 효익 지표. 메타포는 톤만 정한다 |
| 컨셉을 판정하지 않고 비싼 단계로 갔다 | **C 게이트** — 러프 1장으로 사람이 먼저 go / 수정 / 중단. 무인이면 멈춘다 |
| 한글 모바일 타입이 정수 U로 안 나왔다 | UI 스케일 0.25U · 디스플레이 0.5U · 행간 0.25U — 조건부, 등록 단계만 |

### v0.4에서 바뀐 것 — 파일럿 1회차의 교훈

파일럿에서 스킬은 디자인 구조·심미성·UX 관점을 놓치고 1U를 상징화하는 데 몰두했다(결과 화면이 더프롬 로고의 3U·2U·1U 막대와 브랜드 컬러를 닮음). 원인은 스킬만이 아니라 문서에 있었다.

| 원인 | 고친 것 |
|---|---|
| 1U가 "방법"이라고만 했지 **보이면 안 된다**고 하지 않았다 | §2.2.4 "사용자가 1U를 알아볼 수 있다면 실패" · N7 |
| 서비스 브랜드 공백을 더프롬 브랜드로 채울 수 있었다 | §1.1 철학은 판단의 방법 · §3 팔레트는 자사 산출물용 · Q-S0-06 |
| **조형 품질을 판정하는 게이트가 없었다** | **G7 조형 완성도** — Knowhow Book 원칙 7항목 + 포트폴리오 기준 |
| UX는 "해치지 않는가"만 물었다 | G4 ③ 사용자 가치 · 레이어 ③ 동기와 감정 · 재해석 표 `사용자가 얻는 것` |
| 절차·증거에 노력이 쏠렸다 | 우선순위 선언(사용자 경험·조형 > 형식) · 크리틱 루프 2회 · 문서는 표 중심으로 짧게 |

### v0.2에서 확정된 것

| 항목 | 결정 |
|---|---|
| **1U 확장** | 확정. 단 불변 원칙은 아니다 — **1U는 값이 아니라 방법**이다. 고정되는 것은 "하나의 단위에서 모든 치수를 파생시킨다"는 구조이고, 값(8px 등)은 프로젝트가 정한다. 예외 5종 목록 신설 |
| **자메뷰** | 정의 확정 — 익숙한 것을 처음 보는 것처럼 느끼는 것 |
| **G5 판정** | 2단. 1차 **사내 비참여자 3명 이상(필수)**, 2차 외부 타겟(가능하면). 1차의 조건은 '사내'가 아니라 '비참여' |
| **반대 대상 표기** | 고정 형식 신설 — 층위 6종(`CAT` `COMP` `SELF` `PLAT` `ISM` `EXP`) · 강도 3단계(이탈/역전/거부) · **실례 2건 이상 필수** |
