# briefs/ — 팀 브리프 보관

`tools/brief-editor.html`로 쓴 브리프(.md)를 여기에 커밋합니다.

- 파일 이름: 편집기가 만들어 주는 `브리프_프로젝트명_날짜.md` 그대로
- 고칠 때: 편집기의 **불러오기**로 열어 수정 → 다시 저장 → 같은 이름으로 덮어쓰기
- AI에 줄 때: 이 파일을 대화에 첨부하고 "더프롬 방식으로 진행해줘"
- 클라이언트 기밀이 담긴 브리프는 커밋하지 않습니다 — 저장소를 볼 수 있는 모든 사람이 읽습니다

예시: [`예시_브리프_앱인토스_성향_분석.md`](예시_브리프_앱인토스_성향_분석.md)
