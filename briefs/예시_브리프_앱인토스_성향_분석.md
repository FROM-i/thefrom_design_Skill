## ★1. 무엇을 — 서비스와 범위

| | |
|---|---|
| 서비스 한 줄 | 토스 미니앱 '성향 분석' — 토스 정보(성별·생년월일)와 문항으로 성향을 분석하고, 공개를 승인한 결과는 커뮤니티에서 댓글을 받는다 |
| 이번에 만들 범위 | 진입·문항 / 결과 / 커뮤니티 — 3화면 |
| 핵심 흐름 | 토스에서 성별·생년월일 제공 동의 → 8문항 → 결과 → 본인 승인 시 공개 → 댓글 |

## ★2. 누구에게 — 타겟과 상황

| | |
|---|---|
| 누가 | 토스를 매일 쓰는 20~30대. 성향 테스트 경험이 많다 |
| 언제·어디서 | 송금·결제 사이 1~2분 틈 |
| 기기 | 모바일 |

## ★3. 핵심 순간 — 사용자가 얻고 싶은 것

| | |
|---|---|
| 가장 중요한 화면 | 결과 화면 |
| 그 순간 원하는 것 | 이해하고 싶다, 자랑·공유하고 싶다 — "왜 이 결과가 나야?"를 납득하고 싶다. 친구에게 보여줄 한 장도 원한다 |
| 지금 실패하는 지점 | 흔한 결과지는 유형명+캐릭터라 공유는 해도 납득은 안 된다 |

## ★4. 브랜드 — 클라이언트(서비스)의 것

| | |
|---|---|
| 브랜드 컬러·서체·톤 | 없음 — 서비스 약속과 타겟에서 새로 정함 |
| 모기업·플랫폼 브랜드 | 토스 앱 안에서 이질감이 과하면 안 됨 |

## ★5. 제약 — 지킬 것, 금지, 재료

| | |
|---|---|
| 반드시 지킬 것 | 생년월일은 공개 금지. 뒤로 가기·공유 등 익숙한 조작은 유지 |
| 쓰면 안 되는 것 | 유형 라벨로 사람을 나누는 표현 |
| 재료 (첨부) | 문항 8개 초안 (문항_v1.md 첨부) |
